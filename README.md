# 🎸 Tecnologia e Acordes

Portfólio pessoal de Juliana Cândido para compartilhar projetos, estudos e conteúdos sobre tecnologia, inteligência artificial, desenvolvimento de software e música.

## Acesse

- [Site oficial](https://www.tecnologiaeacordes.com.br)
- [Blog original no Blogger](https://tecnologiaeacordes.blogspot.com/)

## Funcionalidades

- Páginas dedicadas para apresentação, capacitações, projetos e contato
- Integração automática com o Blogger
- Páginas individuais para publicações
- Navegação responsiva e acessível
- SEO com metadados, sitemap, robots e dados para compartilhamento
- Sanitização do conteúdo HTML recebido do Blogger

## Tecnologias

| Tecnologia | Uso |
| --- | --- |
| Next.js | Framework e renderização |
| React | Interface |
| TypeScript | Tipagem estática |
| Tailwind CSS | Estilização |
| Blogger | Origem das publicações |
| Vercel | Hospedagem e deploy |

## Desenvolvimento local

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Verificações

```bash
npm run check
npm run build
```

## Estrutura

```text
app/         Rotas, layout e metadados
components/  Componentes da interface
lib/         Integração e utilitários do Blogger
public/      Arquivos estáticos
docs/        Documentação do projeto
```
